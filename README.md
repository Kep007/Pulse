# Pulse

Pulse is a lightweight Windows desktop time tracker for client work.

## Stack

- Tauri 2
- React
- TypeScript
- Rust
- SQLite, planned

## Development

Install prerequisites on Windows:

- Node.js 20+
- Rust stable with Cargo
- Microsoft Visual Studio Build Tools with the C++ workload

Then run:

```bash
npm install
npm run dev
```

## Build Windows Installer

```bash
npm run build
```

The Windows installers are generated by Tauri under `src-tauri/target/release/bundle`.
